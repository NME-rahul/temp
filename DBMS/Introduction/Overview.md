# Database

A database is a collection of related data.

* The database involves specifying data types, structure and constraints for the data.
* Constructing the database is the process of storing the data itself, that is controlled by the DBMS.
* It provides data abstraction by hiding some details of data storage that are not nedded by users.

## Data Model

A data model is collection of concepts that can be used to **describe the structure of the database**. It provieds the necessary means the achieve abstraction.

## Database Schemas

THe description of database is called the database schemas, which is specified during database design and is not expected to change.

A database schema is the skeleton structure that represents the logical view of the entire database. It defines how the data is organized and how the relations among them are asscociated. It formuate all the constriants that are to be applied on the data.

It's the database designers who design the schema to help programmers understand the database and make it useful.

The data at a particular moment in time is called a database state or snapshot.
