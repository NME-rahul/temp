# Indexing

* Indexes are auxiliary(subsidiary) access table.
* The main purpose of indexing is to minimize the number disk access to reduce the query process time.
* The index structure structure typically provides secondary access paths, which provide alternative ways of accessing the record files without affecting the physical placement of records based on disk.
