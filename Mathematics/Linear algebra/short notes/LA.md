1. A matrix is said to be orthogonal if $A \dot{} A^T = I$
2. When a matrix is multiplied by some scalar $k$ then its all row and columns are multiplied by scalar $k$.

$$(kA) = k(A)$$

3. When a determinant is multiplied by some scalar $k$ then its only single row or columns is multiplied by scalar $k$.

$$k^n(A) = (kA)$$ $$(kA) = k^n(A) \\\ \text{     where A is of order of nxn}$$

4. If $det(A) = k$ then $det(A^{-1}) = \frac{1}{k}$
