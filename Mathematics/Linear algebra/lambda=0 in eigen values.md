* Almost all vectors change their direction when they multiplied by a matrix $A$, certain exceptional vector $x$ remains in same direction as $Ax$ these vectors are called eigen vectors.
* Equation $Ax = \lambda x$
  * $x$ is vector multipled by some scalar(we know multiplying vector by some scalar strech, shrink or revers itself but dont change its direction) if matrix A behave like scalar $\lambda$ then $x$ is called eigen vector.

* In any case if $x$ changes its direction then we can say that eigen values are imaginary.
