* If all elements of row/cloumn is zero the determinant is always equal to zero.
* If two rows/coloumns are same in matrix then determinant is always equal to zero.
* Determinant of lower/upper triangular matrix = product of principal diagonal elements
* If a matrix is a singular matrix then inverse of the matrix is not possible.
* If a matrix is a square matrix having dimension above 2x2 and the elements are in sequence then determinant is always equal to zero.
