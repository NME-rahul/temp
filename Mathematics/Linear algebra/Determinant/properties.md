1. If all elements of a row/cloumn is zero the determinant is always equal to zero.
2. If two rows/coloumns are same in matrix then determinant is always equal to zero.
3. Determinant of lower/upper triangular matrix = product of principal diagonal elements
4. If a matrix is a singular matrix then inverse of the matrix is not possible.
5. If a matrix is a square matrix having dimension above 2x2 and the elements are in sequence then determinant is always equal to zero.
6. Taking Transpose does not change determinant. $det(A) = det(A^T)$
7. Determinant of $det(A^{-1}) = \frac{1}{det(A)}$

When determinant changes ?
1. Interchanging row or columns, changes the sign of determinant.
2. $(kA) = k^n(A)$ if k is multiplied by every row and column.
3. If A row or columns is mutiplied by some scalar $k$ then determinant is multiplied by $k$.
4. IF all rows or columns are multiplied by some scalar $k$ then determinant is multiplied by $k^n$.

When determinant does not changes ?
1. Adding multiple of one row/column to another. foe eg. $R_i \rightarrow R_i + k R_j$
