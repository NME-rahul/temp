* A matrix is said to be orthogonal if $A \dot{} A^T = I$
* When a matrix is multiplied by some scalar $k$ then its all row and columns are multiplied by scalar $k$.

$$(kA) = k(A)$$

* When a determinant is multiplied by some scalar $k$ then its only single row or columns is multiplied by scalar $k$.

$$k^n(A) = (kA)$$ $$(kA) = k^n(A) \\\ \text{     where A is of order of nxn}$$
