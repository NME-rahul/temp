# Orhtogonal matrix

* In linear algebra orthogonal matrix is square matrix whose entires are real and the vectors are orthonormal meaning they are perpendicular to each other and each vector have unit length.
* $A^T = A^{-1}$ which implies $A.A^T = I$, because each vector are perpendicular to each other so on $A^T.A$ elements on the principal diagonal will produce 1 because there each vector have produce with itself.
* Determinant of an orthgonal matrix is always either +1 or -1.
* Computer Graphics and Vision: Used to perform rotations, reflections, and coordinate transformations in 3D space.
* Data Science and Machine Learning: Essential for Principal Component Analysis (PCA) to reduce data dimensionality.
