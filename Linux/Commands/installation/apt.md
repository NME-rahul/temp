# Advance Packaging Tool(apt)

* It is a smart package installer in linux systems.

* To install packages

`sudo apt [package-name]`

* To remove packages

  `sudo apt remove [package-name]`

or 

`sudi apt purge [package-name]`
 
or

`sudo apt autoremover` it removes all packages that are no longer needed and installed automatically.


## Searching
* Before downloading any package we should have correct name of particular pcakage and that can be found using command `sudo apt search [keyword]` it will search on the list of packages stored in local system, which can be updated by the command `sudo apt update`
