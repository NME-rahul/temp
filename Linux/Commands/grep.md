# grep (Global Regular Expression Print)

* It is the tool for searching specific pattern in Linux and unix like systems.
* Output: matching lines

* Application: log analysis, incident response and vulnerability hunting


### Log Analysis and intrusion detection
*  When a server is compromised, logs are the most crucial to find the trace of hacker.
  1. Detect Brute Force: Search for failed login attempts in authentication logs.
  2. Finding SQL injection: Look for common SQL keywords in web server access logs.
  3. Identify web shells: search for suspecious PHP functions like `system()` or `eval()` in web directory.
