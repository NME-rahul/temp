# Lexical Analyzer

* The first phase of the compiler is called _lexical analysis or sanning_. 
* The lexical analyzeer reads the stream of character making up the source program and groups the chracters into meaningfull seqeuence callled lexeme.
* the lexical analyzer produce as output a token of the form, $\prec token-name, attribute-value \succ$
* Then it passes to th next phase, syntax analysis.
* TH first component _token-name_ is use during syntax analysis, and the second component _atribute-value_ points to an entry in the symbol table for this token.
