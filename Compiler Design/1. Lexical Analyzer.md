# Lexical Analyzer

* The first phase of the compiler is called _lexical analysis or sanning_. 
* The lexical analyzeer reads the stream of character making up the source program and groups the chracters into meaningfull seqeuence callled lexeme.
* the lexical analyzer produce as output a token of the form, $\prec token-name, attribute-value \succ$
* Then it passes to th next phase, syntax analysis.
* TH first component _token-name_ is use during syntax analysis, and the second component _atribute-value_ points to an entry in the symbol table for this token.

---

  $$position = initial + rate * 60$$

1. $position$ is a lexeme that would mapped into a token $\prec id, 1 \succ$, where id(token-name) is an identifier and 1(attribute-value) points to the symbol table entry for position.

2. $=$ is a lexeme that is maaped as $\prec = \succ$ since this token need no attribute value so we have ommited the second component.
   
3. $initial$ is a lexeme that is mapped into the token $\prec id, 2 \succ$, where 2 points to the symbol-table entry for $initial$.

5. $+$ is alexeme tha is mapped as $\prec + \succ$.
     
6. $rate$ is a lexeme that is mapped into the token $\prec id, 3 \succ$, where 3 points symbol-table entry for $rate$.
     
8. $*$ is lexeme that is maped into the token $\prec * \succ$.

9. $60$ is a lexeme that is mapped into the token $\prec 60 \succ$.

$$\prec id, 1 \succ  \prec = \succ \prec id, 2 \succ \prec + \succ  \prec id, 3 \succ \prec * \succ  \prec 60 \succ$$
