## Multidimensional Data Analysis in Cube Space

Cube Space is an environment where multidimensional models are created using OLAP cubes technologies. These multidimensional database cube models allow users to view their from multiple perspective simultaneously by creating virtual "cubes" that repersents different combinations of dimensions.

OLAP cubes works by aggregating large voluems of transactional-level detail into summary level based on user defined hierarchies across various dimesnions like periods, products sold, geographic regions served etc. The resulting multi-dimensional dataset allows user to drill down into specific areas for further analysis while still maintaining context around related metics within the same cube structure. aking it easier then ever before for analysts who may not have technical experties but still require access to powerful analytics.

#### Techniques for analyzing multidimensional data
1. Cluster Analysis
2. Principal Componene Analysis
3. Factor Analysis
4. Regression Analysis
5. Neural Networks
