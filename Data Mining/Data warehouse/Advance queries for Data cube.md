## Advance Query for exploring Data Cube

1. Multi-dimensional range queries:
These queries find all data points that fall within a specified range of values for two or more dimension. For example, a query migth find all sales records for products in the "Electronics" vateogry that were sold in jaipur region the dates between "24-09-2023" and "30-09-2023".

2. Top-K queries: 
These queries find te top k data points for a given aggregation measure. For example, a query might find the top 10 products by sales in the "Electronic" category in the "New York" region.

3. Trend analysis queries:
These queries find trends in the data over time or across differnet dimensions. For example, a query might find the trend in sales for the "Electronics" category in the "Bikaner" region over the past years.

4. Anamoly detection queries:
These queries find the data points that deviate significantly from the expected values. For example, a query might find all sales recoreds that are more than 2 standard deviation above the mean for the product category and region.
