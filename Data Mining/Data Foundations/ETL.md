# ETL(Extract Load Transform) -

There are three simple methods before performing analysis on data - 

1. Extract - Extraction method involves collecting the data from companies warehouse according to your problem need and discard extra data. Taking useless data in action makes analysis useless so using a good quality data should be your first priority.

2. Load - After collecting good quality data you need to load it in a tool that will helps you in performing needed analytical operation. Data tool can be any it totally depends on analysts choice. Their different data tool are available in market nowdays like Microsoft-excel, PowerBI, Tableu, Google-sheets etc.

3. Transform - This step involves data cleaning. Every data needs preprocessing before peforming analysis. Data transformation step involes changing data type, data shape/dimension, handling missing values, typos errors etc.
