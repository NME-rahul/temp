# Firewall

* A firewall is a network security system that monitors and controls incomeing and outgoing traffic based on predefined secuirty rules.
* Acts as a barrier between trusted internal networks and untrusted external networks like the internet.
* It is avaiable as hardware as well as software, it works on the application layer.


## Application
* Prevention of Unauthorized access
* Block Malicious Traffic
* Protect Sensitive Information
* Control Network Usage
* Mitigate Insider Risks
