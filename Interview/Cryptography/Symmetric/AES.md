# AES(Advance Encryption Standards)
* AES is a Block cypher.
* The size of key is determined by the block Size.


## Applications of AES
1. Wireless security
2. Database Encryption
3. Secure Communications
4. Data Storage
5. Secure torage of Passwords

* A famous use case is 'Google Widevine' used to encrypt the licenced content over the internet.
