# DHCP

* The Dynamic Host Configuration Protocol (DHCP) dynamically assigns IP addresses to hosts by leasing them for a specified period. When this lease expires the DHCP server usually assigns renew the IP if available otheriwse assigns a new IP from pool.
* It uses UDP as Transportaion layer protocol.
* Port 67: Used by DHCP server to listen requests
* Port 68: used by client to send message
