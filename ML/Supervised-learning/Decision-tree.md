# Decision tree

* A decision support hierarchical model uses a tree like model.
* It is used for both classification and regression task.
* A decision-tree makes decision by partioning the data into subset.
* Each internal node represents a feature/attribute or we can say quetion or split point.
* Each leaf node represents the outcome or label.

  ![](https://www.mastersindatascience.org/wp-content/uploads/sites/54/2022/05/tree-graphic.jpg)


### Application

1. **Medicine**: Diagnosing medical conditin based on symptoms and test results.
2. **Business**: Customer segmentation, product recommendation systems, and risk assesment in finance.
3. **Engineering:** Fault diagnosis and system control engineering.
4. **Marketing**: Predicting customer behaviour and market segemntation for targeted adverising.
5. **Environmental Science**: Clasification of species based on envrionmental factors.
