### There are two main aaproaches to implementing a contrl unit

* Hardwired control unit
* Micro-programmed control unit

### Hardwired Control unit

The hardwired control unit can be seen as state machine that changes from one state to another in every clock cycle, depending upon the instruction register, condition codes, and external inputs. The sequence of operations are carried out by the this machine.

* It uses a fixed set of logic gates coressponds to the some boolean expression that executes instructions.
* Hardwired control is faster.
* RISC architecture is based on the hardwired control unit.
* Inflexible because it is impossible to change the hardware after implementation.

### Micro-programmed Control unit

* The control signals associated with operations are stored in special memeory units.
* Control signals are generated by a program that is similar to machine language programs.
* The micro-programmed control unit is slower in speed because of the time it takes to fetch instruction from control memory.
* A microassembler is used to translate the control word that is stored in the control memory.

Standard micro-instruction format:-
|Control signals|Mux Select|Next Address|
|---|---|---|

* Control Signal: Each bit indicate whether the coressponding device will take action or not.
* Mux select: flag bits/condition bits.
* Next Address: Address of the next micro-instruction.(these bit are used onto control memmory to fetch next address).

||Hardwired control unit|Micro-programmed control unit|
|---|---|---|
|Implementation|Fixxed set of logic gates and circuits|Microcode stored in memory|
|Flexibility|Less flexible, difficult to modify|More flexible, easier to modify|
|Instruction set|Supports limited instruction sets|Supports complex instruction sets|
|Complexity of Design|Simple design, easy to implement|Complex design, more difficult to implement|
|Speed|Fast operation|slower operation due to microcode decoding|
|Debugging and testing|difficult to debug and test|Easier to debug and test|
|Size and cost|Sammler size, lower cost|larger in size, higher cost|
|Maintenance and upgradibilty|Difficult to upgrade and maintain|Easier to upgrade and maintain|
