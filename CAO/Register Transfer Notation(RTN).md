# Register Transfer Notation(RTN)

* Register Transfer Notation (or RTN) is a way of specifying the behavior of a digital synchronous circuit. It is said to be specification language for this reason.
* Provides a fromal means of describing machine structure and function.
* Used to describe what machine is doing without how the machine doing.
* It helps to understand new machine design concept.

RTN may be written as either abstract or concrete.Abstract RTN is a generic notation which does not have any specific machine implementation details. In contrast, concrete RTN is a notation which does implement specifics of the machine for which it is designed. The possible locations in which transfer of information occurs are:

1. Memory-location
2. Processor Register
3. Registers in I/O device
